2. REKOMENDASI TIPE DATABASE
-------------------------------------------------------------------------------

Rekomendasi Utama: PostgreSQL (dengan TimescaleDB Extension)
Alasan:
- Data Time-Series: Data monitoring tanda vital (BPM, SpO2, Suhu) dikirim 
  setiap detik dari ESP32. TimescaleDB sangat cepat untuk query berbasis waktu 
  dan efisien hemat penyimpanan.
- Relasi ACID: Sangat andal untuk mengelola Dokter/Perawat (Users), data Pasien,
  dan Perangkat IoT (Devices).

Alternatif: MySQL 8.0 / MariaDB / MongoDB (jika mengutamakan NoSQL).


-------------------------------------------------------------------------------
3. STRUKTUR & SPESIFIKASI TABEL DATABASE
-------------------------------------------------------------------------------

A. Tabel: users (Sistem Login & Autentikasi)
   - id            : UUID / BIGSERIAL (Primary Key)
   - username      : VARCHAR(50)      (UNIQUE, contoh: dr_budi)
   - email         : VARCHAR(100)     (UNIQUE)
   - password_hash : VARCHAR(255)     (Enkripsi Bcrypt / Argon2)
   - role          : VARCHAR(20)      ('admin', 'doctor', 'nurse')
   - full_name     : VARCHAR(100)     (Nama Lengkap untuk UI)
   - created_at    : TIMESTAMP        (Default CURRENT_TIMESTAMP)

B. Tabel: patients (Data Pasien ICU / Ruangan)
   - id                : VARCHAR(20)  (Primary Key, contoh: P-001, P-002)
   - medical_record_no : VARCHAR(50)  (Nomor Rekam Medis / RM)
   - full_name         : VARCHAR(100) (Nama Pasien)
   - age               : INTEGER      (Usia)
   - gender            : VARCHAR(10)  ('L' / 'P')
   - room_no           : VARCHAR(50)  (Ruang / Bed)
   - status            : VARCHAR(20)  ('active', 'discharged')

C. Tabel: devices (Registrasi Perangkat IoT)
   - device_id  : VARCHAR(50) (Primary Key, contoh: ESP32-ICU-01)
   - patient_id : VARCHAR(20) (Foreign Key ke patients.id)
   - status     : VARCHAR(20) ('online', 'offline', 'error')
   - last_seen  : TIMESTAMP   (Ping terakhir alat)

D. Tabel: vital_signs_history (Log Telemetri Sensor)
   - id          : BIGSERIAL                (Primary Key)
   - patient_id  : VARCHAR(20)              (Indexed FK ke patients.id)
   - device_id   : VARCHAR(50)              (FK ke devices.device_id)
   - bpm         : SMALLINT                 (Heart Rate)
   - spo2        : SMALLINT                 (Saturasi Oksigen %)
   - suhu        : DECIMAL(4,2)             (Suhu °C)
   - recorded_at : TIMESTAMP WITH TIME ZONE (Indexed DESC)
